# 项目说明

项目是创建要给文件中转服务，解决多地域网络连通、内外网安全性等问题，提供安全、便捷的文件中转服务。

## 多地域网络连通与数据安全

为解决这个问题，通过将读写连通性、权限分离，对于公开访问过接口仅提供写功能，仅开放内网或指定环境的读权限。

# 技术架构

项目主要用于解决文件中转痛点，瓶颈在 IO 而非 CPU，故选择 python3 作为基础语言，服务框架选择 FastAPI。

# 服务部署

通过 Docker Image 的方式打包服务，可选择 Docker、Docker Compose 等工具部署。

# 更多说明

1. 读、写分离，可指定相同端口，支支持指定不同端口
2. 支持灵活的上传 path，比如 {host:port}/{user}
3. 支持指定数据保存路径
4. 对文件进行随机字符串编码，仅在上传时给出包含编码后的文件下载路径
5. 注意系统安全，通过机制避免安全漏洞，比如移除文件执行权限

# 预期使用方式

1. 上传

```
上传命令
curl --upload-file path/to/file {host:port}/{user-name}
// 返回
{host:port}/{user-name}/{encode-file-name}
```

```
下载命令
wget {host:port}/{user-name}/{encode-file-name}
```
